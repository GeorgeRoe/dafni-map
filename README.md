# DAFNI Map

Work experience project hosted by DAFNI within STFC.

Simple map web application to browse partners of DAFNI and explore their work.

You can access the GitHub Pages site [here](https://georgeroe.github.io/dafni-map/).

## Development

To run the project locally:

```bash
# First install dependencies
npm i

# Spin up the development server
npm run dev
```
